# GTA San Andreas FullPack with MoonLoader
This FullPack contains: gta_sa.exe version 1.0 US (patch), CLEO, ModLoader, MoonLoader, Silent's ASI Loader, SilentPatchSA, Widescreen fix, and the **d3d9.dll** file which **runs the game** in **windowed mode**.

# Auto Installer
- I have created a new Auto Installer for you, which will download and install CLEO (+ CLEO+ and NewOpcodes extensions + AudioFix + GTA SA 1.0 US) completely automatically! All you need to do is [**download this**](https://github.com/sakulmore/GTA_SA__FullPack_with_MoonLoader/releases/latest) single Batch file.

# Manual Installation
- Download the FullPack
- Copy all the contents of the .rar file into the root directory of the game (make sure you have a clean installation of the game)
- Open the file `GTASA.WidescreenFix.ini` in the folder `C:\Program Files (x86)\Steam\steamapps\common\Grand Theft Auto San Andreas\scripts` (or simply wherever you have the game installed) and set the resolution you want (or leave it as default: 0, 0)
- Done

# Notes
- If you want to play in fullscreen and not in windowed mode, simply delete the d3d9.dll file.
